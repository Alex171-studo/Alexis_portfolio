🎯 Sujet de l’exercice

Écrire un programme en langage C qui calcule le Plus Grand Commun Diviseur (PGCD) de deux entiers en utilisant l’algorithme d’Euclide.

📘 Rappel théorique

Le PGCD de deux entiers est le dernier reste non nul lorsqu'on fait une division euclidienne successive de a par b. 

⚙️ Fonctionnalités du programme

Gestion des entiers positifs et négatifs.

Cas particuliers :

pgcd(0, n) = |n| pour tout entier 𝑛≠0
pgcd(0, 0) est indéfini.
Utilisation d’une boucle while pour appliquer l’algorithme d’Euclide.
