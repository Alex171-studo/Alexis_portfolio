Vérification de nombre premier en C

📌 Description

Ce projet implémente en langage C une fonction qui vérifie si un entier donné est un nombre premier.
Un nombre premier est un entier supérieur à 1 qui n’est divisible que par 1 et par lui-même.

Exemple :

2, 3, 5, 7, 11 sont premiers

4, 6, 8, 9, 10 ne le sont pas

Le programme utilise la bibliothèque math.h pour calculer la racine carrée et réduire le nombre de divisions nécessaires.
