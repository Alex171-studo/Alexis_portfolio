Décomposition en facteurs premiers en C
📌 Description

Ce programme en langage C permet de décomposer un entier positif en facteurs premiers.
La décomposition en facteurs premiers est l’expression d’un nombre entier comme un produit de nombres premiers, éventuellement élevés à une puissance.

Fonctionnalités

Demande à l’utilisateur d’entrer un entier positif.

Affiche la décomposition en facteurs premiers sous la forme classique :

n = p1^a1 * p2^a2 * ... * pk^ak


Gère les cas particuliers :

0 → message spécial (pas de décomposition en facteurs premiers).

1 → affichage direct de 1.
