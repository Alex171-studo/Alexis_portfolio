# Port Scanner

Scanner de ports TCP basique en Python.

⚠️ **USAGE LÉGAL UNIQUEMENT**
Ne scannez que vos propres systèmes ou avec autorisation explicite.

## Features
- Scan ports TCP communs
- éésolution DNS incluse
- Rapport résultats

## Usage
```bash
# Scan localhost
python3 port_scanner.py hostname liste_des_ports

# Scan IP des ports  connus 
python3 port_scanner.py hostname
```

## Ports scannés
21 (FTP), 22 (SSH), 80 (HTTP), 443 (HTTPS), 3306 (MySQL), etc.
