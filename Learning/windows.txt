	WMI (Windows Management Instrumentation), une interface d’administration qui permet d’obtenir ou de modifier des informations système.

	Get-WmiObject -Class win32_OperatingSystem | select Version,BuildNumber : afficher la Version de windows et le numéro de build

	🔍 Autres classes WMI utiles
	Classe				Description
	Win32_Process		Liste des processus en cours
	Win32_Service		Liste des services (et leur état)
	Win32_Bios			Informations sur le BIOS (firmware de la carte mère)
	
## REMOTE ACCESS
On peut utiliser RDP(Remote Desktop Protocol).RDP fonctionne généralement sur le port 3389

	xfreerdp est souvent utilisé pour se connecter de linux vers windows

	xfreerdp /v:<targetIp> /u:<username> /p:Password

type <filename> : afficher le fichier

RDP : Remote Desktop Protocol utilisé pour se connecter à un ordinateur , utilise le port 3389

## WMI : Windows Management Intrumentation
	# Services : reçoit les demande et redirige au bon endrtoit
	#Managed objects : ce qui est surveillé ou contrôlé
	#WMI providers: les espions qui permettent de surveiller ou contrôler
	#Classes: les types d'infos (processeur, OS)
	#Methodes: les actions 
	#VMI Repository : là où les fichiers sont stockés

Pour y accéder soit avec 
	C:\> wmic
	wmic:root\cli>
	
Soit wmic et la commande 
	 C:\> wmic computersystem get name
Exemples:
	- wmic computersystem get name : nom du pc
	- wmic os list brief : info sur l'OS
	- wmic process list brief: liste les processus
	- wmic process where name="notepad.exe" delete : stopper
	-wmic logicaldisk get name,size,freespace : info sur le disque
