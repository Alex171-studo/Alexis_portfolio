# Log Parser

Script Python basique pour analyser des fichiers de logs.

## Features
- Compte erreurs/warnings
- Extrait IPs avec regex
- Affiche statistiques

## Usage
```bash
python3 log_parser.py fichier.log
```

## Exemple
```bash
python3 log_parser.py test.log
```
